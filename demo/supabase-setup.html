Supabase update: admin panel

Adds the admin dashboard totals, user list, role management and a log of role changes. Admins never see anyone's health data. Safe to run more than once.

Open SQL Editor
  1. Tap Copy script.
  2. Tap Open SQL Editor (project wellness-jumpstart).
  3. Delete anything already in the editor, paste, and click Run. It should finish with “Success. No rows returned”.
